# Lab-4.2-Array-Manipulation
Build efficient functionality to add, remove, and filter data from arrays based on user interactions.

## Reflection Questions

### 1. How did array methods like `push()` and `filter()` help you manipulate data in this activity?

`push()` helped me add new items to the array, while `filter()` helped me find and display items that matched certain conditions.

### 2. What challenges did you face when trying to filter and search for items in the array?

One challenge was making sure my conditions were written correctly so the search returned the right items.

### 3. How would you modify this code to make it more efficient or user-friendly?

I would add a simple user interface with input fields and buttons so users can add, search, and filter items without using the console.
